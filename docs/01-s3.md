# Stage 1: S3 Integration (Amazon Simple Storage Service)

## Design Decisions: Why S3 Integration is Structured This Way

For this project, we decouple our AWS S3 interface into a controller-service architecture:

```
Request ──> S3Controller ──> S3Service ──> Laravel Storage (Flysystem) / S3 SDK ──> LocalStack S3
```

### 1. Separation of Concerns
By implementing `S3Service`, the controllers do not need to understand connection status codes, S3 Client configurations, or prefix parsing logic. The controller simply delegates S3 business logic to the service and focuses on HTTP requests, request validation, flash notifications, and page rendering.

### 2. Laravel Filesystem Abstraction vs. Native AWS S3 Client SDK
- **Laravel Storage Disk (`s3`):** Great for simple object operations like `Storage::disk('s3')->put()`, `delete()`, or `exists()`. It handles abstracting direct API streams.
- **Native AWS S3 Client SDK (`Aws\S3\S3Client`):** Essential for bucket-level management operations (such as listing, creating, and deleting buckets) and handling direct hierarchical prefixes/delimiters (`CommonPrefixes` representing virtual folders).
- **Combined Approach:** In `S3Service`, we initialize the SDK client dynamically via Laravel's filesystem driver using `Storage::disk('s3')->getClient()`. This ensures that we read configs directly from Laravel's environment (`.env` and `config/filesystems.php`), avoiding duplicate client initialization or hard-coding endpoints.

## Service Functions Summary (`app/Services/S3Service.php`)

Here is an overview of the key functions in our service layer and how they achieve our S3 requirements:

### 1. `getClient(): \Aws\S3\S3Client`
Fetches the underlying native AWS SDK client from Laravel's `s3` storage disk wrapper. This ensures we inherit all authentication and LocalStack endpoint credentials.

### 2. `getConnectionStatus(): array`
Performs a lightweight `listBuckets()` call inside a `try-catch` block.
- If it succeeds, it returns `['connected' => true, 'error' => null]`.
- If a connection exception occurs (e.g. LocalStack is offline or misconfigured), it catches the exception and returns `['connected' => false, 'error' => $errorMessage]`, preventing a crash and allowing user-friendly diagnostics to be rendered in the browser.

### 3. `listBuckets(): array`
Fetches all active buckets on LocalStack using `listBuckets()`. For each bucket, it queries the bucket's region location (`getBucketLocation`) and counts current objects via `listObjectsV2`.

### 4. `createBucket(string $name, ?string $region = null): void`
Enforces S3 bucket naming regulations and creates a bucket on LocalStack.
- *AWS Region Constraint:* For the default `us-east-1` region, a `LocationConstraint` is not permitted in the `CreateBucketConfiguration` parameter. The service handles this condition dynamically by omitting the configuration block if the region is `us-east-1`.

### 5. `deleteBucket(string $name, bool $force = false): void`
Deletes a bucket from S3.
- If `$force` is `true`, it first issues recursive S3 delete commands to purge all objects inside the bucket.
- If `$force` is `false` and objects exist, it blocks the action to demonstrate standard S3 safety constraints.

### 6. `listObjects(string $bucketName, string $prefix = ''): array`
Retrieves objects and folders within a bucket hierarchical directory style.
- Uses `Delimiter => '/'` and the requested `$prefix` (e.g. `uploads/`).
- Returns two lists: **virtual folders** (from `CommonPrefixes`) and **files** (from `Contents`), facilitating folder-level navigation (breadcrumbs).

### 7. `uploadFile(string $bucketName, UploadedFile $file, string $prefix = ''): void`
Uploads files to S3 under the chosen directory prefix. The service streams the file into S3 using a readable resource stream to conserve memory.

### 8. `downloadFile(string $bucketName, string $key)`
Retrieves the object via `getObject` stream and returns it as a binary stream download. No S3 credentials, secrets, or raw S3 URLs are exposed directly to the client browser.

### 9. `previewObject(string $bucketName, string $key)`
Enables inline previews of image and PDF file formats. The service reads the object and returns it as a direct Laravel binary stream response with the correct MIME type (e.g., `image/jpeg` or `application/pdf`), allowing safe, CORS-free visual rendering.
